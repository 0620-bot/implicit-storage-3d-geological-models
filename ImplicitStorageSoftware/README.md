# Precompiled Software for Implicit Storage and Cross-Section Generation (with Example Data)

This folder provides the **precompiled software package** corresponding to the source code in this repository. It is intended for reproducing the workflow presented in the paper, including **implicit storage**, **multiscale model reconstruction**, and **implicit cross-section generation**.

Users can run the software directly by launching `ImplicitStorage.exe`.  
For a full interface-level demonstration, please refer to the demo video provided in the GitHub Release of this repository.


## Runtime Notes

- This software is intended for **64-bit Windows** systems.
- Please keep `ImplicitStorage.exe`, all `.dll` files, and all subdirectories in this folder **in their original relative locations**. Deleting or moving these files may prevent the program from running correctly.
- The folders `data/`, `iconengines/`, `imageformats/`, `platforms/`, and `translations/` contain required runtime dependencies for the Qt-based application.


## Folder Contents

- `ImplicitModel/` – Example model data. This folder contains the implicit surface results used in the paper’s case study, including stratigraphic interfaces and structural implicit surfaces.
- `ImplicitSection/` – Default output folder for generated implicit cross-section results.
- `ImplicitSurfdata/` – Intermediate data generated during implicit surface processing. These files are not required as final output results.
- `multiscaleModel/` – Default output folder for reconstructed multiscale model results.
- `data/`, `iconengines/`, `imageformats/`, `platforms/`, `translations/` – Runtime dependency folders required by the Qt application. Do not delete them.
- `ImplicitStorage.exe` – Main executable program.


## Main Output Files

- `ModelSurf.txt` – Generated after the implicit storage step. This file is created in the same directory as `ImplicitStorage.exe` and is used as the input for subsequent multiscale reconstruction and implicit cross-section generation.
- `multiscaleModel/*.obj` – Explicit mesh models reconstructed at different scales.
- `ImplicitSection/*.obj` – Cross-section results generated by the implicit sectioning workflow.


## Basic Workflow

1. Run `ImplicitStorage.exe`.
2. In the **implicit storage** module, load the implicit surface results of the example model from the `ImplicitModel/` folder and execute the storage process. After completion, the software will generate `ModelSurf.txt` in the same directory as the executable.
3. In the **multiscale model reconstruction** module, use `ModelSurf.txt` as the input, set the target scale/resolution parameters, and generate explicit mesh models at different scales. The reconstructed results are saved in `.obj` format in the `multiscaleModel/` folder.
4. In the **implicit sectioning** module, again use `ModelSurf.txt` as the input, set the required sectioning parameters, and perform section generation. The current implementation supports **polyline sectioning**. The generated section results are saved in `.obj` format in the `ImplicitSection/` folder.
